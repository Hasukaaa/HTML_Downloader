# HTML Editor & Downloader

ブラウザ上で動作するシンプルなHTMLエディタです。HTMLを書いて、ボタン一つでHTMLファイルとしてダウンロードできます。

## 機能

- **コードエディタ** - 行番号付きのダークテーマエディタ
- **HTMLダウンロード** - 書いたHTMLをファイルとしてダウンロード
- **ライブプレビュー** - リアルタイムでHTMLの表示を確認
- **ファイル名変更** - ダウンロードするファイル名をカスタマイズ
- **タブ入力対応** - Tabキーでインデント入力
- **ステータスバー** - カーソル位置・文字数を表示

## 使い方

1. `index.html` をブラウザで開く
2. エディタにHTMLを入力する
3. 画面下部の「HTML ダウンロード」ボタンをクリック
4. HTMLファイルがダウンロードされる

## GitHub Pages で使う

このリポジトリのGitHub Pagesを有効にすると、ブラウザから直接アクセスして使えます。

Settings > Pages > Source を `main` ブランチに設定してください。
